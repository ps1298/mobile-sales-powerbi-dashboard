# 📊 Mobile Sales Dashboard | Power BI

An interactive Power BI dashboard analyzing mobile phone sales performance across cities, brands, and payment methods — built to support data-driven decision-making in retail sales operations.

## 📌 Project Overview

This project explores a mobile sales dataset to uncover trends in revenue, customer behaviour, and brand performance. The dashboard was designed to answer key business questions such as:

- Which cities are driving the most sales?
- Which mobile brands dominate in quantity and revenue?
- What payment methods do customers prefer?
- How do sales fluctuate across days and months?
- How are customers rating their purchases?

---

## 📈 Key Insights

| Metric | Value |
|--------|-------|
| 💰 Total Sales | ₹58.77M+ |
| 📦 Total Quantity Sold | 1,000+ units |
| 🔄 Total Transactions | 291 |
| ⭐ Average Customer Rating | Tracked across all brands |

- **Top Cities:** Delhi and Mumbai lead in total sales contribution
- **Top Brand:** Samsung recorded the highest total sales and quantity
- **Payment Trends:** Cash remains the most preferred payment method, followed by UPI and Credit/Debit Cards
- **Day-wise Patterns:** Clear peaks and troughs in daily sales volume identified
- **Customer Ratings:** Distribution analysed across rating categories (1–5)

## 📊 Dashboard Features

- **Dynamic Filters** — Filter by Mobile Model, Brand, Payment Method, and Day
- **City-wise Sales Treemap** — Visual breakdown of revenue by city
- **Brand Comparison Table** — Side-by-side sales, quantity, and transaction data
- **Payment Method Donut Chart** — Distribution of Cash, UPI, Credit Card, Debit Card
- **Day-wise Sales Trend** — Line chart showing daily revenue patterns
- **Customer Rating Bar Chart** — Distribution of ratings across the dataset
- **KPI Cards** — Total Sales, Average Sales, Total Quantity, Transactions at a glance

## 💡 Business Value

This dashboard enables retail managers and business stakeholders to:

✅ Identify top-performing cities and allocate resources accordingly

## 🚀 How to Use

1. Download the dataset from the `/dataset` folder
2. Open Power BI Desktop
3. Load the dataset using **Get Data → Excel/CSV**
4. Recreate the visualizations using the insights documented above
5. Apply DAX measures for KPI cards and calculated columns

> 📝 *Note: The .pbix file is not included in this repository. The dataset and documentation are provided to reproduce the analysis.*
